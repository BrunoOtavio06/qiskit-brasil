# Qiskit Fall Fest 2026 — São Paulo

Website for the Qiskit Fall Fest 2026 edition hosted in São Paulo, Brazil. Built with [Next.js](https://nextjs.org).

## About the event

Qiskit Fall Fest is a Qiskit community event held at universities across the world. This edition runs **November 24–26** in a hybrid format — in-person at FIAP (Faculdade de Informática e Administração Paulista) and virtually open to students from any university.

The program includes talks, a workshop, and a hackathon, all aimed at beginners with no prior background in math, physics, or programming.
